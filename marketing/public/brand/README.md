# tidybridge brand

Everything here is published at `https://tidybridge.dev/brand/<file>`.
All logo and image files are generated by `marketing/scripts/build_brand.py`
from a handful of constants (colors, tagline), so change them there and
re-run it rather than editing the files by hand:

```
cd marketing
uv run --with fonttools --with brotli --with uharfbuzz python scripts/build_brand.py
```

## Logo

| File | Use |
|---|---|
| `lockup-on-light.svg` / `lockup-on-dark.svg` | Default logo: mark + wordmark. Documents, decks, headers |
| `wordmark-on-light.svg` / `wordmark-on-dark.svg` | When the mark is already shown nearby, or space is wide and short |
| `mark-on-light.svg` / `mark-on-dark.svg` | The bridge arc alone, transparent background |
| `mark-tile.svg` (+ 64, 512 px PNG) | App icon / favicon: the mark on a dark rounded tile |
| `avatar.png` | LinkedIn and Google profile picture (400×400, cropped to a circle) |
| `linkedin-banner.png` | LinkedIn profile banner (1584×396, content kept clear of the photo) |
| `email-signature.html` | Gmail signature, instructions inside |
| `../og-image.png` | Link preview image (1200×630) used by `index.html` |

PNG copies sit next to each SVG for places that don't take SVG (LinkedIn,
Gmail, Word, Slides). Use "on-light" files on light backgrounds and
"on-dark" files on dark ones.

**Rules**
- The wordmark is always one word, lowercase: **tidybridge**, never
  "TidyBridge" or "Tidy Bridge". "tidy" in the text color, "bridge" in
  emerald.
- Clear space around the logo: at least the height of the letter "t".
- Smallest size: lockup 96 px wide on screen, mark 16 px.
- Don't recolor, stretch, rotate, outline or add effects to the logo, and
  don't put it on a busy photo or a mid-tone background.

## Colors

The same values as the site (`marketing/src/index.css`). Emerald is the only
accent; everything else is warm grey (Tailwind "stone").

| Role | Light mode | Dark mode |
|---|---|---|
| Background | `#fafaf9` stone-50 | `#0c0a09` stone-950 |
| Surface (cards) | `#ffffff` | `#1c1917` stone-900 |
| Text | `#1c1917` stone-900 | `#fafaf9` stone-50 |
| Secondary text | `#57534e` stone-600 | `#a8a29e` stone-400 |
| Borders | `#e7e5e4` stone-200 | `#44403c` stone-700 |
| **Accent** (buttons, "bridge", links) | `#047857` emerald-700 | `#34d399` emerald-400 |
| Accent tint (highlights) | `#d1fae5` emerald-100 | `#065f46` emerald-800 |

Use the accent sparingly: one primary action or highlight per view. The two
accents differ on purpose: emerald-700 is the one with enough contrast on
light backgrounds, emerald-400 on dark ones.

## Type

- **Geist** for everything: headings semibold (600) with slightly tight
  letter spacing, body regular (400).
- **Geist Mono** for code, payloads, IDs and numbers shown as data.
- Both are free (SIL Open Font License): https://vercel.com/font. Where
  Geist isn't available (Word, Gmail), use Arial / Helvetica.

## Voice

Plain and specific. Say what the product actually does today ("doubtful
values are flagged, not guessed"), never what it might do. No claims about
accuracy until the eval has numbers, no client names without permission.
