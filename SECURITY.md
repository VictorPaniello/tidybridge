# Security

Found a vulnerability in tidybridge? Please report it privately to
**hello@tidybridge.dev** rather than opening a public issue. Include what
you found, how to reproduce it, and what it lets someone do.

You'll get a reply within a few days. tidybridge is a personal project run
by one person, so there's no bug bounty - but every report is read, fixed
when valid, and credited in the CHANGELOG if you'd like.

Please don't test against other people's accounts or data, and don't run
load or denial-of-service tests against tidybridge.dev; a local copy (see
the README) is enough for almost anything.
